## Context
现有共享创作台保存草稿、参考图、任务和来源，并通过图像编辑接口实现带参考图生成。
## Goals / Non-Goals
完成角色档案和模板组合创作闭环。第一版单次选择一个角色，不实现自动拆三视图、角色训练或多人身份绑定。
## Decisions
- 本地 characters.json 存储独立档案，版本校验和原子写入保护并发修改；移除档案为软删除，保留作品及共享图片。
- 设定图复用上传接口，仅接受已存在的本地图片路径；封面从设定图选择，默认第一张。
- 共享创作台保存角色资料快照。角色参考图优先，额外参考图合计最多三张，超限明确提示。
- 角色页按角色和模板稳定标识隔离草稿；提示词页保留原有草稿结构，增加可选角色。
- 最终提示词明确设定图只用于身份特征，画风、场景、姿势和排版由模板与本次任务决定。角色名变量可自动填写，其他变量继续由用户填写，不猜测设定。
- 作品从已有创作记录按角色 ID 聚合，不另存重复图像；提交时保存角色/模板快照，改图和送画布延续来源。
## Risks / Trade-offs
- 模型可能照搬设定图 → 区分身份参考与本次构图要求，最终正文可查看；真实模型测试仅证明本次结果。
- 其他页面更新角色 → 重开选择器或刷新载入最新档案；已保存草稿保留快照，主动重选才替换。
- 修改档案不能改写历史 → 历史结果保留提交时快照。
## Migration Plan
无旧数据迁移；首次读取为空。新增导航和接口，旧提示词无角色时行为保持兼容。
