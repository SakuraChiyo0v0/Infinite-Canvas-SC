## Why
用户常用角色设定图搭配姿势、场景、风格模板生成角色图片，反复上传资料和切换页面不方便。
## What Changes
- 与提示词并列的角色页：名称、封面、最多三张设定参考图、可选背景介绍。
- 左侧角色列表、中间资料、右侧复用创作台；角色页选择模板就地生成。
- 提示词创作台也能选择角色，将角色身份与模板的画风、场景、构图分别组合。
- 角色作品集聚合生成结果，保存角色和模板快照，支持继续修改。
## Capabilities
### New Capabilities
- `character-library`: 角色档案、双入口创作和作品来源。
### Modified Capabilities
无。
## Impact
新增本地角色 JSON 存储及 API、角色页；扩展共享提示词创作台、来源快照和导航。复用本地上传、图像任务、画布接口，不改网关。
