## Context
展开主侧栏后素材库位于更窄的 iframe，原 360/640/360 最小列宽不可用。
## Goals / Non-Goals
五个 tab 均保留目录、列表、详情的横向关系；不调整业务逻辑。
## Decisions
普通页目录约 19%，余下空间按 0.9:1.1 分配给列表和详情。提示词页目录 19%、列表 25%、详情占剩余空间。
各栏允许收缩，工具栏换行；窄宽度减少目录缩进并允许名称换行。三栏整体最小宽度 714px，极窄窗口通过横向滚动保持可读性。
提示词预览标题和备注保持自然高度，正文容器占用右栏剩余空间，最小 240px；正文移除 136px 默认高度及 520px 上限，随容器伸展，内容超出时内部滚动。小高度窗口允许右栏整体滚动。
## Risks / Trade-offs
极窄屏不堆叠三栏，因此需要横向滚动。桌面以展开侧栏的实际 iframe 验证。
