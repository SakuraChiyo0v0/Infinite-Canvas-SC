## ADDED Requirements
### Requirement: 素材库横向三栏
素材库所有 tab SHALL 保持目录、列表、详情从左到右排列，展开主侧栏后仍保留该结构。
#### Scenario: 展开主侧栏浏览素材库
- **WHEN** 用户在桌面窗口展开主侧栏并切换五个素材库 tab
- **THEN** 三个面板保持同排，右侧完整可见，工具栏在栏内换行
#### Scenario: 编辑提示词
- **WHEN** 用户打开新增提示词表单
- **THEN** 中间列表压缩，右侧获得更多正文宽度，保存和取消按钮可见
#### Scenario: 极窄窗口
- **WHEN** 可用宽度不足以容纳三栏最小可读宽度
- **THEN** 保留横向结构并允许横向滚动
#### Scenario: 提示词正文利用右栏高度
- **WHEN** 用户在右栏预览提示词
- **THEN** 正文区域填满标题与备注之外的剩余高度，不受固定 136px 高度或 520px 上限限制；超长正文在区域内滚动
