# 验证记录

## 实现范围

- 智能画布新增「收集并保存」节点，通过生成节点输出连到收集节点输入后启用。
- 未连接保持既有普通/循环输出形式；已连接的输出收集到单个节点，逐张保存。
- 收集配置、保存状态和记录随画布持久化；失败保存可以重试，不调用模型。
- 默认显示最近 6 张图片，完整记录每页 12 张。保存目录属于后端所在机器。
- 不修改生成服务自身输出目录；最终文件从现有生成资源复制或下载后保存。

## 限制与交付

- 未实际调用 API / CLI / ComfyUI 模型，未验证外部生成服务可用性。
