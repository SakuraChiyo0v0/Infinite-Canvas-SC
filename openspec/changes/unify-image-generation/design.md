## Context

目前 zimage.html 和 online.html 分别维护文生图和在线生成，后者包含参考图、质量、批量与 RunningHub 参数适配。ModelScope 在前后端有独立实现和自动配置逻辑。

## Goals / Non-Goals

**Goals:** 合并生图入口；一个模型下拉框决定路由；删除 ModelScope 专属能力并安全保留旧内容。

**Non-Goals:** 不删除历史图片、密钥、配置数据，不修改软件更新源，不提交或部署。

## Decisions

- 以 online.html 的完整生成逻辑为统一实现，收紧为工作台布局；zimage.html 作为兼容跳转，导航仅保留一个生图入口。
- 模型选项使用 provider/model 二元组编码，标签包含模型与服务商，避免同名模型冲突；本地 Z-Image 作为明确的独立选项，不存在隐式跨服务切换执行。
- 统一历史展示 online 与 zimage 两种记录；本地沿用 /api/generate，远程沿用 /api/online-image，不新增生成服务。
- 服务商加载和保存均过滤退役的内置 ModelScope；后端拒绝旧请求，专用 HTTP 路由移除。保留磁盘数据，不自动迁移旧模型到其他服务。
- 旧 msgen 节点采用不可执行的占位显示，保留原对象和连线；旧聊天/智能画布引用明确报错。
- 其他图片工具移除 ModelScope 来源，并合并本地/远程模型选项。

## Risks / Trade-offs

- 工作区已有改动 → 先保存源码快照，只增量修改。
- 旧配置/节点重新启用退役服务 → 过滤默认注入、保存与查询路径，增加回归验证。
- 未配置引擎 → 显示空态或未配置提示，不伪造远程模型、不静默换服务执行。
- 本地文生图不支持参考图 → 提示切换编辑模型或移除参考图，禁止静默丢弃。

## 补充决定

用户补充确认：去掉图像工具分组标题和折叠按钮；文生图名称统一为「生图」。
