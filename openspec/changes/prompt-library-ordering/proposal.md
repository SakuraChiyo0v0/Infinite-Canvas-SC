## Why
提示词库、分组与条目无法按个人使用习惯整理，管理顺序需要与生成和画布中的选择顺序一致。
## What Changes
- 库、分组、提示词支持拖拽排序；分组与条目可跨库移动，条目可跨组移动。
- 排序持久化，使用入口读取相同顺序；移动保留正文、效果图、草稿、配方。
- 拖拽显示目标位置，禁止虚拟只读库的移动，过期操作拒绝覆盖。
## Capabilities
### New Capabilities
- `prompt-library-ordering`: 提示词层级排序与跨层级移动。
### Modified Capabilities
无。
## Impact
提示词数据处理、素材管理拖拽、工作台稳定关联及各提示词选择器。复用 JSON 存储，不引入依赖。
