## ADDED Requirements
### Requirement: 层级拖拽整理
系统 SHALL 允许库、分组、提示词排序，并允许分组跨库、提示词跨组和跨库移动。
#### Scenario: 跨库移动分组
- **WHEN** 分组被拖到另一个库
- **THEN** 分组及其条目完整移动，冲突 ID 安全重建，原内容和创作记录不丢失
#### Scenario: 条目排序与归组
- **WHEN** 提示词被拖到条目前后或目标组
- **THEN** 保存对应顺序或分组；搜索过滤不影响其他条目
### Requirement: 顺序联动
系统 SHALL 在管理页、主页选择器和画布选择器采用同一份持久顺序。
#### Scenario: 刷新使用入口
- **WHEN** 顺序已修改后打开或刷新提示词选择器
- **THEN** 库、分组、提示词以保存后的顺序显示
### Requirement: 数据保护
系统 MUST 拒绝失效目标和过期拖拽，不移动只读虚拟内容。
#### Scenario: 并发修改
- **WHEN** 请求版本落后于已保存数据
- **THEN** 拒绝覆盖并提示刷新，源和目标均不发生部分移动
