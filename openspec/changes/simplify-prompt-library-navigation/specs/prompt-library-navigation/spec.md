## ADDED Requirements

### Requirement: 折叠与浏览分离
系统 SHALL 允许独立展开和折叠库，记住展开状态；首次只展开当前库。点击库名称查看全部条目，点击分组仅查看该组，标题显示库与分组。

#### Scenario: 首次和再次进入
- **WHEN** 用户首次进入后展开其他库并刷新
- **THEN** 首次仅展开当前库，刷新后恢复用户设置的展开状态

#### Scenario: 折叠当前库
- **WHEN** 用户折叠当前库
- **THEN** 内容筛选不变，目录不出现重复的全部提示词行

### Requirement: 稳定的管理入口
系统 SHALL 使用行尾菜单管理对应库或分组；打开菜单和选中行不改变行高与名称位置，菜单不能被目录边界裁剪，支持键盘操作。

#### Scenario: 管理非当前库
- **WHEN** 用户打开非当前库菜单后关闭
- **THEN** 当前筛选和编辑草稿保持不变，Escape 可关闭菜单并恢复焦点

#### Scenario: 执行管理动作
- **WHEN** 用户在菜单中选择重命名、新建分组或删除
- **THEN** 操作作用于该菜单对应目标，切换目标前保留既有草稿确认，重命名输入在原行且删除仍需确认

### Requirement: 独立拖拽入口
系统 SHALL 只从目录行独立手柄启动库与分组拖拽，保留排序、跨库移动和条目拖入库或分组行为。

#### Scenario: 浏览不误拖
- **WHEN** 用户拖动名称或点击菜单按钮
- **THEN** 不启动目录排序

#### Scenario: 合法拖放
- **WHEN** 用户从手柄拖动分组至另一个库
- **THEN** 使用既有移动协议保存，显示目标库并保留提示词内容
