## Context
现有 asset-manager 通过整块渲染管理三栏，目录选中态决定是否插入管理工具条。排序接口和分组移动已实现，需保留既有数据契约和草稿保护。

## Goals / Non-Goals
Goals：稳定的可折叠目录，明确浏览和管理入口，保留排序与跨库移动。
Non-Goals：修改后端、数据结构、其他素材导航或右侧创作台。

## Decisions
- 展开库 id 集合保存在独立 localStorage 键，首次只展开当前库；折叠按钮不切换筛选。
- 名称按钮与展开、更多、拖拽按钮为同级控件，不嵌套 button；选择库即查看全部内容。
- 更多菜单使用 fixed 定位的独立浮层，避免滚动容器裁剪，也不改变目录高度；菜单目标显式绑定库与分组，打开菜单不改变当前内容。Escape、外部点击与滚动关闭。
- 管理操作触发后沿用草稿保护，再选定目标执行现有接口；重命名输入替换原行，新建库在头部、新建分组在所属库内。
- 导航行保留拖放目标属性，只有专用手柄 draggable；条目拖拽行为不变。
- 样式限定到提示词导航，继续使用现有颜色与 Lucide 图标。

## Risks / Trade-offs
- 折叠后跨库分组目标隐藏 → 允许用户先展开库，库行本身继续接收拖放。
- DOM 重绘丢失菜单与输入焦点 → 菜单独立渲染，输入显式聚焦，关闭菜单恢复触发按钮焦点。
- 未保存模板可能被管理操作切换 → 复用 leavePromptEditor 并覆盖取消场景。
