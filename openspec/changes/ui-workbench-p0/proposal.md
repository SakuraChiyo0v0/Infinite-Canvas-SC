## Why

UI 审查（2026-09-21）确认当前界面存在四类问题：随窗口自动整体缩小（窄窗口最低缩到 68%）、核心标签字号偏小（9-11px）、参数区与主操作被大面积空白分隔、多层卡片与装饰间距占用首屏。结果是"看着空、读起来累"。本次先把基础可读性规范落地，再把文生图页做成样板，验证效果后再推广到其余图片工具。

## What Changes

- 取消默认的整页自动缩放：界面缩放仅保留用户显式选择的百分比，默认 100%；窄窗口改由页面响应式布局承担。画布世界坐标的 zoom/pan 不受影响。
- 在 `static/css/theme.css` 建立共享设计令牌（字号、行高、控件高度、间距、圆角、颜色），供各页面复用；图片工具共享控件 `static/js/cli-image-tools.js` 改为引用令牌。
- 主导航宽度改由显式按钮控制并持久化，hover 只显示名称提示，不再改变内容区宽度；压缩导航项间距。
- 文生图页（`static/zimage.html`）改为参数栏 + 结果区的工作台布局：左侧 340px 参数栏、主按钮固定在参数栏底部、右侧"结果 / 历史"切换、结果区 contain 展示 + 最近结果缩略图。
- 修复 API 设置页推荐服务卡片中 Key 输入框与保存按钮被裁切的问题，并统一该页中英文混用。

## Impact

主要影响 `static/zimage.html`、`static/index.html`、`static/js/theme.js`、`static/css/theme.css`、`static/js/cli-image-tools.js`、`static/js/i18n/studio.js` 以及 API 设置相关文件。不改动后端接口、请求字段、运行数据与本地凭证，不包含提交 / 推送 / 部署。
