## ADDED Requirements

### Requirement: 界面默认不整体缩放

系统 SHALL 默认以 100% 显示界面，不再根据窗口尺寸自动缩小整页；窄窗口 MUST 通过布局重排适配内容，画布自身的世界坐标缩放与平移 MUST 保持原有行为。

#### Scenario: 窄窗口打开工具页
- **WHEN** 用户在 743px 宽窗口打开文生图页
- **THEN** 界面缩放值为 1，页面不出现横向溢出，参数区与结果区纵向排列且主操作在首屏可达

#### Scenario: 默认缩放取值
- **WHEN** 用户未手动选择过界面缩放
- **THEN** 实际缩放为 100%，历史遗留的 `auto` 取值同样按 100% 处理

### Requirement: 共享界面令牌

系统 SHALL 在共享主题样式中定义字号、行高、控件高度、间距、圆角与颜色令牌，页面与共享控件 MUST 引用这些令牌而非各自硬编码，核心操作文字 MUST 不小于 12px。

#### Scenario: 图片工具共享控件
- **WHEN** 文生图、在线生图、图片编辑、细节增强或角度控制渲染服务选择与输出尺寸控件
- **THEN** 控件使用共享令牌的字号与高度，标签与选项可读且不裁切

### Requirement: 导航宽度由显式操作控制

主导航 SHALL 仅通过显式按钮在收起与展开之间切换，并保存用户选择；指针悬停 MUST NOT 改变导航宽度或内容区布局。

#### Scenario: 悬停导航
- **WHEN** 用户将指针移到主导航上但不点击
- **THEN** 导航宽度不变，仅通过提示文本显示入口名称

#### Scenario: 切换并保持导航状态
- **WHEN** 用户点击导航展开按钮后刷新页面
- **THEN** 导航维持展开状态，展开宽度为 208px

### Requirement: 文生图采用参数集中、结果优先的工作台布局

文生图页 SHALL 使用固定宽度参数栏与弹性结果区，主操作 MUST 固定在参数栏底部；结果区 SHALL 提供结果与历史两种视图、图片按比例完整展示以及最近结果缩略图。

#### Scenario: 桌面宽度下的默认布局
- **WHEN** 用户在 1440x900 打开文生图页
- **THEN** 参数栏宽度为 340px，主按钮高 44px 且完整可见，结果区显示结果与历史切换

#### Scenario: 生成后查看结果
- **WHEN** 用户提交生成并返回结果
- **THEN** 结果视图展示该图片，最近结果缩略图新增一项，空态与生成中状态隐藏，主按钮恢复可再次点击

### Requirement: 生成请求字段保持不变

布局改造 MUST NOT 改变各引擎分支的请求字段与历史归类。

#### Scenario: 本地引擎
- **WHEN** 用户以本地引擎提交提示词
- **THEN** 请求包含 prompt、width、height、type=zimage 与 client_id

#### Scenario: CLI 引擎
- **WHEN** 用户以已配置的 CLI 图像服务提交提示词
- **THEN** 请求包含 prompt、provider_id、model、size 与 history_type=zimage

### Requirement: API 设置表单不裁切

API 设置页的推荐服务卡片 SHALL 在容器宽度不足时纵向排列输入与保存动作，输入框与保存按钮 MUST 完整可见。

#### Scenario: 窄容器下的推荐卡片
- **WHEN** 用户在 743px 宽窗口查看 API 设置的推荐服务
- **THEN** Key 输入框与保存按钮均在卡片边界内完整可见，不被裁切
