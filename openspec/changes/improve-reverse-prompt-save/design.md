## Context
反推页已有结果草稿与提示词库新增接口，但保存表单只提供名称和库。

## Goals / Non-Goals
目标：减少命名和定位操作，让保存状态清晰。非目标：改变模型、自动语义分类、改动其他页面或库管理接口。

## Decisions
- 反推工作区高度使用窗口动态高度除以现有界面缩放比例，图片区和正文区占用剩余高度；操作区不随正文滚动。保存字段在宽窗口横排，窄窗口保留可读尺寸。
- 保存表单常驻结果底部，名称留空时使用正文首个有效短句，允许手动覆盖。
- 库和分组并排，记住每个库上次成功保存的分组，失效位置回退到有效选项。
- 保存前重新读取库，检查目标仍存在并检查同库同分组中完全相同正文（且无独立负向词），避免普通重复操作产生副本。不覆盖既有条目。
- 反馈位于保存按钮旁；请求期间冻结保存字段和结果，失败保留内容供重试。

## Risks / Trade-offs
- 截取内容生成名称不等同于模型摘要，用户可编辑，避免额外模型请求。
- 前端查重不保证多个标签页同时提交时的原子性；本次不引入后端幂等接口。
