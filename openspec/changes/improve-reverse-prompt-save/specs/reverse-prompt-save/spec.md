## ADDED Requirements

### Requirement: 单屏反推工作区
桌面反推页 SHALL 按当前窗口与界面缩放分配高度，左右布局中输入、开始反推、结果和保存操作均在首屏可见，长正文在文本框内滚动。

#### Scenario: 展开侧栏和保存区域
- **WHEN** 用户在常见桌面窗口打开反推页并展开主侧栏
- **THEN** 页面不因图片或长正文产生整页纵向滚动，开始反推和保存按钮可见

### Requirement: 便捷选择保存位置
系统 SHALL 展示可编辑名称和库、分组选项，并记忆上次成功保存的位置。

#### Scenario: 连续保存
- **WHEN** 用户保存成功后刷新反推页
- **THEN** 默认选中上次保存的库和分组，名称为空时采用正文建议名称

#### Scenario: 位置失效
- **WHEN** 记忆的库或分组已被删除
- **THEN** 页面选择有效位置，保存前再次核实目标，失效时提示重新选择

### Requirement: 就地反馈且避免重复保存
系统 SHALL 在保存区显示进行中、成功、失败状态，并检查同位置同正文的已有条目。

#### Scenario: 保存成功
- **WHEN** 保存请求成功
- **THEN** 显示实际库与分组，不再允许相同内容重复提交

#### Scenario: 保存失败
- **WHEN** 接口失败
- **THEN** 保留输入并在保存区提供错误反馈，允许重试
