## ADDED Requirements

### Requirement: CLI shortcut dimensions match provider cards
The API settings sidebar SHALL render each CLI shortcut button with the same outer height and corner radius as the sidebar's provider cards.

#### Scenario: Viewing CLI shortcuts in API settings
- **WHEN** a user opens the API settings page
- **THEN** the 即梦 CLI, GPT CLI, and Antigravity CLI shortcut buttons each have a 52 px outer height and a 10 px corner radius
- **AND** their labels, icons, and click actions remain available
