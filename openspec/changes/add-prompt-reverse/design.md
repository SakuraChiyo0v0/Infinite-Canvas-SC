## Context
现有 caption_image_with_provider 已支持对话模型识图，上传图片和提示词库已有接口。主页使用懒加载 iframe。
## Goals / Non-Goals
目标：独立反推入口、指定导航顺序、可编辑和复用结果。非目标：还原原作者真实提示词、批量素材分类或新增供应商。
## Decisions
- 新增 /api/prompt-reverse，仅允许项目本地图片 URL，验证图片后复用识图服务。
- 用户在一个下拉框选择供应商与对话模型组合；不把生图模型当作识图模型，不自动跨供应商切换。
- 左侧输入图和模型，右侧完整提示词；结果在同页编辑、复制、保存词库。
- 生成页面转交用同源 sessionStorage 单次消费和父页面消息通知；编辑页同时带参考图，无自动生图。
- 页面保存当前图片、正文及模型草稿；请求期间禁止换图和重复提交，失败保留已有结果。
## Risks / Trade-offs
- 部分对话模型不支持图片 → 明示选择支持识图的模型，错误原样呈现，不自动重试。
- 反推只能近似描述 → 页面说明不能恢复原始提示词。
- 图片可能含有指令文字 → 固定分析提示要求仅把图中文字当作视觉内容。
