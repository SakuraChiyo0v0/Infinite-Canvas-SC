## Context

现有前端由独立页面和 iframe 工作区组成，无框架迁移需求。当前工作区含大量未提交开发成果，本次须在其基础上增量修复。审阅截图位于 outputs/ux-audit-2026-09-22。

## Goals / Non-Goals

**Goals:** 消除已定位的键盘障碍、表单裁切、草稿丢失和错误反馈误导。

**Non-Goals:** 不重设计整体风格，不改服务协议与数据格式，不执行付费生成，不改用户已有内容。

## Decisions

- 延用原有按钮、颜色和样式体系，主导航采用原生按钮与可见焦点；非活动 iframe 从交互和辅助技术树隐藏，仍保留页面状态。
- 工作区异步请求先校验再更新，加载错误持续显示并可重试，新建/移动/重命名成功后才显示成功；失败保留输入与原始状态。
- 新建浮层保持正常阅读尺寸并限定在可视区域，不受画板缩放影响。
- 提示词编辑草稿保存在页面状态中，搜索重绘恢复草稿，显式切换/取消前保护未保存内容。删除沿用现有确认文案并使确认真实生效。
- 保留桌面三栏，窄窗口改为可纵向浏览的布局，避免最小宽度把主要操作推到屏外。
- 三个子智能体按互不重叠的文件分工：工作台；素材/提示词；导航/表单/角色。主智能体审阅整合与浏览器验收。

## Risks / Trade-offs

- [已有修改与本轮混合] → 先保存相关文件基线，按本轮差异复核，禁止 reset 或整文件回退。
- [真实删除和付费生成不可作为随意测试数据] → 采用隔离测试替身覆盖失败/删除分支，浏览器只验证非破坏性交互。
- [截图不能证明全面无障碍合规] → 补充键盘和 DOM 检查，报告验证边界。
