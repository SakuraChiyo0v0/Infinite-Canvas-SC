## Context
上一版工作台以页面内存保存草稿，同步生图请求刷新后无法接回结果。画布已有任务队列、节点生成元数据及 JSON 持久化。

## Goals / Non-Goals
目标：六项创作体验完整串联；兼容已有词库和画布。非目标：更换图像协议或改造网关。

## Decisions
- 本地服务 JSON 文件分别保存 drafts、recipes、covers；记录级版本检查、原子写入。浏览器即时备份草稿并显示保存失败，避免静默丢失。
- 使用现有图像任务接口，保存 task_id 和不可变请求快照；刷新只恢复轮询，不自动重复提交。
- 模板默认展示中文变量和本次任务，固定正文收于高级编辑；未知变量保留原名，已有模板无需批量改写。
- 封面由用户上传或实际结果设定；首张真实结果可自动成为封面，标明参考图需求，不使用无关示意图冒充效果。
- 配方独立保存正文、变量、模型、尺寸、可选参考图，可命名、应用、覆盖更新和删除。
- 一句话修改以选定结果及其实际提示词作为基底，新要求后置且优先，保留父结果 ID、参考图、模型与时间。
- 送入画布包括参考图节点、提示词节点、结果节点和可见来源连接；结果保存 provenance 快照。画布来源面板和分支操作兼容原有 runMeta，老图无来源时不虚构。

## Risks / Trade-offs
- 服务重启导致内存任务过期 → 明确提示检查历史，不自动重新生图。
- 多页面同时编辑 → 版本冲突保留浏览器备份并提示，禁止覆盖新版本。
- 封面可能未生成 → 显示“暂无效果图”，提供上传及结果设为封面。
- 原接口不保证请求幂等 → 创建任务响应丢失时标记状态未知，不自动重试。
