## Why
工作台已能就地生成，但挑选模板仍靠读长文、刷新丢草稿、重复填写参数，生成后缺少连续修改和来源追溯。

## What Changes
- 模板缩略图、用途标识和手动设置封面。
- 中文任务填写项，长正文收进高级编辑。
- 独立保存常用配方及参考图，自动保存草稿与结果。
- 每张结果支持一句话修改，保留原始约束与来源快照。
- 画布展示生成来源，并可从任意有来源的结果回到工作台创建分支。

## Capabilities
### New Capabilities
- `prompt-creation-flow`: 提示词创作状态、配方、预览与可追溯改图。
### Modified Capabilities
无。

## Impact
提示词工作台、素材列表缩略图、画布来源操作、本地 JSON 状态接口；复用图像任务与画布接口。已有词库保持兼容，不变更网关。
