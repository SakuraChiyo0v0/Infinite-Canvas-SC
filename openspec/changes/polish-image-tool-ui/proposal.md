## Why
生图页紧凑易用，但缺少其他工具页的标题层次；其他工具页留白过大。用户确认只统一生图、细节增强、图片编辑、角度控制四页 UI。

## What Changes
- 保留紧凑操作区，统一英文粗斜体标题、中文功能副标题和 Archive 历史区。
- 统一控件字号、圆角、间距和窄屏布局，角度控制保留三维交互区域。
- 不改变模型选择、请求、历史数据、导航或其他页面。

## Capabilities
### New Capabilities
- `image-tool-presentation`: 四个图片工具的紧凑视觉规范。
### Modified Capabilities
无。

## Impact
四个静态 HTML 页面与仅由这些页面引用的样式文件；无后端、依赖和数据变更。
