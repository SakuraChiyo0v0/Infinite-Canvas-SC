## Context
现有页面使用静态 HTML、Tailwind 和 theme.css。生图页已收紧布局，其余页面仍有大间距。
## Goals / Non-Goals
Goals: 四页统一粗斜体英文标题、中文副标题、Archive 分区及紧凑控件。
Non-Goals: 不更改导航、业务脚本、模型调用或数据。
## Decisions
增加四页专用 image-tools.css，通过页面类隔离；避免修改全局 theme.css。前三页使用 340px 参数列与弹性预览列；角度页保留双排布局并缩小间距。标题 32px，参数标签 14px，控件 40px，主按钮 44px。英文标题为固定视觉标识，中文副标题使用已有翻译键。
## Risks / Trade-offs
旧 Tailwind 与暗色主题覆盖可能冲突 → 浏览器检查四页及窄屏；三维区域不能过度压缩 → 保留独立最小高度。

## 角度控制补充
角度页使用专用末尾样式，桌面上方卡片显式设置受视口约束的高度，三维 canvas 脱离固有尺寸撑高，参数与结果区顶部对齐。窄屏纵向排列，保留自然滚动。

角度控制改为输入图 / 相机与提示词参数 / 结果预览三栏，工作区使用可视高度，相机预览自适应余量。桌面操作无需滚动；归档仍在首屏下方，手机保留纵向可访问布局。

控制面板视觉修订：相机采用近方形预览与右侧短滑块；提示词、模型、画幅和按钮收进统一面板，模型及画幅同排，焦点使用轻描边。
