## ADDED Requirements
### Requirement: 四页统一紧凑视觉
系统 SHALL 只在生图、细节增强、图片编辑和角度控制应用英文粗斜体标题、可翻译功能副标题和 Archive 分区，保留现有操作行为。
#### Scenario: 桌面工具布局
- **WHEN** 用户在桌面打开四个工具页
- **THEN** 页头和历史区无大面积装饰留白，参数字号清晰，按钮靠近参数，原有模型和上传操作可用。
#### Scenario: 窄屏操作
- **WHEN** 其他工具页宽度小于 850px，或角度控制页宽度小于 650px
- **THEN** 参数与预览纵向排列，无横向溢出，角度控制三维预览保持可见。

#### Scenario: 首屏聚焦操作
- **WHEN** 用户打开四个工具页且尚未滚动
- **THEN** 操作区域 SHALL 至少占满首屏可用高度，归档位于首屏下方；参数间距保持紧凑，超出一屏的操作内容正常滚动。

#### Scenario: 角度控制桌面单屏
- **WHEN** 用户在桌面视口打开角度控制，包含固定展开的导航栏
- **THEN** 输入图片、相机及提示词参数、结果预览 SHALL 左右三栏显示；模型、画幅和生成按钮在首屏可见，归档位于工作区下方。
