## Context
测试记录来自 2026-09-21 至 22 的真实请求。网关原图选择及样式问题已修复。
## Goals / Non-Goals
修复已发现缺陷，真实呈现模型能力。不开创新资产认证 API，不安装整套 ComfyUI 或下载模型，不声称提示词能保证精确像素。
## Decisions
在线增强只读取本地图像，运行本地模型时才上传到 ComfyUI。网页模型保留画幅设置，使用原生分辨率并将画幅加入出图要求。旧移除服务节点保留内容并禁止执行；聊天设置恢复到已配置的有效模型。隐藏不支持认证的平台。补足 websockets 依赖并验证握手。
## Risks / Trade-offs
用户明确没有 ComfyUI：本地模型入口默认关闭，只在可选设置中手动启用。旧本地画布保留但不自动跨平台执行。工具页原本地默认值迁移为列表首个已配置在线模型，用户指定但失效的在线模型仍要求重新选择。
当前产品无日志连带删图入口，不恢复过期删除实现；将旧测试替换为当前保存日志、媒体保留和回收站恢复契约。保存版本必须递增，防止同毫秒写入绕过旧版本检查。
本地服务未启动不能由前端修复；若无已配置安装位置，报告阻塞而不下载大型依赖。网页模型对画幅仍有执行偏差，应显示实际输出尺寸。
