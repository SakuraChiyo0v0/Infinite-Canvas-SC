## Context
现有素材管理已支持词库 CRUD，在线生图接口以 operation 区分生成与编辑。

## Goals / Non-Goals
目标：独立导航、三栏管理、就地生成、模板变量、结果复用。非目标：重做模型协议、迁移词库、改变其他工具。

## Decisions
- 以 asset-manager.html#prompts 复用词库管理，独立模块渲染右侧创作区，避免复制整个管理页面；hash 避免已有静态版本重写器吞掉查询参数。
- 草稿按词库和提示词 ID 存于页面内存，变量替换生成最终预览，显式保存正文才 PATCH 模板。
- 复用 /api/providers 与 /api/online-image，参考图为空时 generate，否则 edit；使用现有本地上传接口。
- 生成请求持有草稿快照；切换模板不会错放结果，失败保留输入、不自动重试。
- 结果保存沿用生图历史；送到新画布使用现有画布创建和保存接口，将最终提示词与结果放入两个节点，成功后打开画布，不覆盖用户原画布。

## Risks / Trade-offs
- 模型支持能力各异 → 仅展示现有可用图像模型，服务错误原样反馈。
- 长模板占空间 → 正文和结果内部滚动，桌面保持三栏；小屏允许横向滚动。
- 草稿为本次页面会话 → 界面明确临时修改，刷新前需主动保存。
